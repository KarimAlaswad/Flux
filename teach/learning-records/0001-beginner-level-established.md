# Beginner level established for system design

The user self-identifies as a beginner with system design — no formal background. However, they have built a non-trivial application (Flux, with Tauri v2 + Rust + React + plugin architecture) which means they have *practical experience* with design decisions even without the vocabulary to name them. This is important: future sessions should bridge between concepts they already understand implicitly (modularity via plugins, interfaces via the RPC protocol) and the formal terminology.

## Implications

- Lessons should avoid assuming knowledge of formal design patterns
- But should leverage their existing understanding of Flux's architecture as a concrete reference point
- The "read the code" exercises will be effective because they already know where things live
