# Beginner level established for effect/coeffect theory

The user is new to formal effect and coeffect theory. They built Flux with a plugin system, so they understand the practical problems (plugin cleanup, dependency ordering, hot reload) but don't have the vocabulary or formal model. This is the same gap that existed in the system design workspace — practical intuition without formal language.

## Implications

- Lessons should teach concepts from first principles, using Flux as the concrete comparison
- The paper's formalism (algorithms, proofs) is out of scope — just the ideas
- TypeScript syntax is a barrier — explain TS constructs when they appear
- The user can read and understand code — "read the source" exercises will work
