# Visual learning preference and ground-up teaching style

The user is a visual learner and needs concepts explained from the ground up. They called out that I skipped too many foundations in lesson 0002 (what a Proxy is, what tools are, what registering means). They want:

1. Every concept explained visually with diagrams
2. Everything built from the ground up (explain JS primitives before using them)
3. Research-backed teaching (verify against source code before teaching)
4. Visual metaphors and ASCII diagrams for abstract concepts

## Implications

- Future lessons must start with "what is X?" before "how does X work in Cordis?"
- Use ASCII diagrams extensively for: object relationships, data flow, state machines
- Every code example should have a visual diagram showing what it does
- Never assume the user knows JS/TS concepts -- explain them inline
- Do research before each lesson to verify accuracy against source code
